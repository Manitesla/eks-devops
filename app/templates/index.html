AWS EKS DevOps Assignment

End-to-End Kubernetes Deployment using Terraform, Docker, Helm, GitHub Actions, Prometheus and Grafana

☁ AWS Infrastructure

Infrastructure provisioned using Terraform including VPC, subnets, IAM, ECR and Amazon EKS.

☸ Amazon EKS

The application is running as multiple Kubernetes pods on an Amazon EKS managed node group.

🐳 Docker & ECR

Application container images are built with Docker and securely stored in Amazon ECR.

⎈ Helm

Kubernetes Deployment, Service, Ingress and ServiceMonitor are managed using a custom Helm chart.

⚙ CI/CD

GitHub Actions automatically builds images, pushes them to ECR and deploys to EKS using Helm.

🔐 GitHub OIDC

GitHub authenticates securely with AWS using OIDC without storing permanent AWS credentials.

📊 Prometheus

Application and Kubernetes metrics are collected using Prometheus and ServiceMonitor.

📈 Grafana

Application availability, request rate, CPU and memory metrics are visualized using Grafana dashboards.
